# Vision Altitude

## Regles editoriales SEO

Appliquer ces regles aux prochaines modifications de metatitres et de metadescriptions. Ne pas reecrire les pages existantes uniquement parce que ces consignes sont ajoutees.

1. Le service ou le sujet recherche vient en premier dans le titre. Exemple : "Photographie aérienne à Laval".
2. La marque est toujours a la fin du titre, sous la forme " | Vision Altitude", jamais au debut.
3. Pour les mentions geographiques generales, utiliser "Montréal, Laval, Rive-Nord". Ne plus utiliser "Grand Montréal" dans les metatitres et metadescriptions. Conserver la ville propre a chaque page locale. Cette regle ne demande pas de supprimer les mentions presentes dans le contenu visible.
4. Viser environ 60 caracteres pour un titre et respecter un maximum de 155 caracteres pour une description. Compter le texte decode, espaces et ponctuation compris, pas les entites HTML.
5. Terminer la description par une action lorsqu'il reste assez de place : "Demandez une soumission." ou "Appelez le 438 496-0332.". Ne pas ajouter une seconde invitation si la description en contient deja une.

## Application des demandes

- Si seul un titre ou une description est fourni, modifier uniquement le champ demande. Ne pas changer automatiquement le H1 ou les autres textes visibles.
- Synchroniser les balises Open Graph correspondantes lorsqu'elles existent.
- Pour les screenshots en tableau : la colonne de gauche identifie la page, celle de droite contient le nouveau texte ; ignorer la colonne du milieu.
- Respecter les formulations explicitement fournies. Signaler un depassement des objectifs de longueur au lieu de raccourcir ou reformuler sans demande.
- Pour l'ajout automatique d'un appel a l'action aux descriptions courtes : laisser les pages legales et les pages non indexees inchangees. Ne pas raccourcir une description pour faire tenir l'invitation ; ne l'ajouter que si le resultat respecte les 155 caracteres maximum.
